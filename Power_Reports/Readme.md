# Power Estimation Reports

This folder contains the post-synthesis power analysis reports generated by the `report_power` utility in Xilinx Vivado.

## Methodology
The reports utilize **vector-based power estimation**[cite: 2]. By feeding the corresponding `.saif` files into the utility, the dynamic power calculation ($P_{dynamic} = \alpha \cdot C_{eff} \cdot V_{DD}^2 \cdot f_{clk}$) uses actual simulated switching activity ($\alpha$) rather than vectorless statistical approximations.

## Key Findings Documented Here
*   An extreme static leakage power draw of 13.357 W (Z-score: 118.4) resulting from combinational trigger logic creating crowbar current paths.
*   Reports for T1, T3, and T4 show a slight decrease in dynamic power, yielding signal-to-noise ratios (-2.8 dB to -4.1 dB) below the traditional threshold for single-metric detection.
